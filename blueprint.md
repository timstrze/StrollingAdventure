# Strolling Adventure - App Blueprint

## Overview

A simple and visually appealing single-page Angular application. It displays a title and an image, with a clean and modern design.

## Implemented Features (v1)

### Style and Design:

*   **Typography:** Uses the "Inter" and "Inter Tight" font families.
*   **Color Palette:**
    *   Bright Blue
    *   Electric Violet
    *   French Violet
    *   Vivid Pink
    *   Hot Red
    *   Orange Red
    *   Grays for text
*   **Layout:**
    *   Centered content.
    *   Responsive design that adapts to smaller screen sizes.

### Features:

*   **Home Page:**
    *   Displays the application title.
    *   Displays a feature image (`sun-color-2020-09-26.jpg`).
    *   The image is responsive and fits the screen width.

## Current Plan

No active plan. The application is in a stable state.
